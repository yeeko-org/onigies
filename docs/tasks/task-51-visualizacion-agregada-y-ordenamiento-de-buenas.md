# Visualización agregada y ordenamiento de buenas prácticas en el dashboard

Hoy las buenas prácticas se listan pero no se pueden ordenar ni comparar entre sí. `[40:52]` «¿Cómo las vas a ordenar y así? Ahorita no hay ninguna visualización como que sumen, ni que multipliquen, ni que hagan nada. Como que no las puedes ordenar».

No es lo mismo que [[task-32]]: aquella es la exportación a Excel con una columna por criterio, un entregable de archivo. Esta es la vista dentro del dashboard —totales, ordenamiento por puntuación— que sirve mientras se revisa. Comparten el dato subyacente y conviene resolverlas cerca.

**Falta una definición antes de construir:** Rubí quedó de conversar el criterio de ordenamiento y agregación (`[40:29]` «Te falta conversar cómo vamos a...»). Qué se suma, qué pondera y en qué orden salen es decisión suya, no de implementación.

## Criterios de aceptación

- [ ] Las prácticas se pueden ordenar por puntuación en el dashboard
- [ ] La vista muestra el total agregado de cada práctica
- [ ] El criterio de agregación quedó definido con Rubí antes de implementarlo
